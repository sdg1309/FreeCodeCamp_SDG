# FreeCodeCamp_SDG

Este repositorio tiene como objetivo guardar y documentar mi proceso de aprendizaje en FreeCodeCamp.  
Aquí se encuentran ejercicios, proyectos, apuntes y prácticas realizadas durante los distintos cursos y certificaciones de la plataforma.

## Contenido

- Ejercicios prácticos
- Proyectos de certificación
- Apuntes personales
- Pruebas y experimentos
- Avance por módulos y tecnologías

## Tecnologías vistas

A lo largo del proceso se trabajan diferentes tecnologías, entre ellas:

- HTML
- CSS
- JavaScript
- Python
- Git & GitHub
- Responsive Design
- APIs
- Bases de datos

## Objetivo

El propósito de este repositorio es:

- Llevar un registro de mi progreso
- Practicar desarrollo de software constantemente
- Mejorar mis habilidades de programación
- Construir un portafolio de proyectos

## Créditos

Gran parte del contenido, ejercicios y proyectos desarrollados en este repositorio están inspirados en los cursos y certificaciones de [FreeCodeCamp](https://www.freecodecamp.org/learn), una plataforma gratuita dedicada a la enseñanza de programación, desarrollo web y ciencias de la computación mediante aprendizaje práctico.

## Nota

Este repositorio está en constante actualización a medida que avanzo en los cursos y desafíos de FreeCodeCamp.
